📊 الأحداث المطلوبة (App Events):

App Open
يتم تشغيله عند فتح التطبيق
View Content
عند فتح صفحة منتج
يجب أن يحتوي:
content_ids (SKU أو ID)
content_type = product
content_name (اختياري)
Add To Cart
عند إضافة منتج للسلة
يحتوي:
content_ids
content_type = product
value (إن وجد)
currency = JOD
Initiate Checkout
عند بدء عملية الدفع
يحتوي:
value (إجمالي السلة)
currency = JOD
content_ids
num_items
Purchase (الأهم)
بعد إتمام الطلب بنجاح فقط
يحتوي:
value (قيمة الطلب)
currency = JOD
content_ids
content_type = product
order_id

⚠️ شروط مهمة:

لا يتم إطلاق Purchase قبل إتمام الطلب
لا يتم تكرار Purchase event
العملة دائمًا JOD
استخدام نفس product IDs الموجودة في Shopify إن أمكن
إضافة console logs أو debug logs لكل Event
إضافة تعليقات داخل الكود توضح مكان كل event
